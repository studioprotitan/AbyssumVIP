# **App Name**: The Arenas of Echelon

## Core Features:

- VLAAD Cinematic Landing: A high-fidelity landing page featuring VLAAD-gothic typography, dynamic glitch effects, persistent ember particle continuity, and cinematic camera views to initiate operator immersion.
- Phase State Engine (LOADING, LANDING, STREAMING): Manages core application state transitions (LOADING, LANDING, STREAMING), ensuring Single Source of Truth (SSoT) through a deterministic flow validated by 'Drift Sentry' and 'Sentinel' systems, orchestrating cinematic events and UI states.
- Mount Bond Awakening QTE: A cinematic Quick-Time Event system, dynamically generating inputs as a tool for operators to initiate a player-mount bond. QTE success/failure directly triggers animated sequences, camera cuts, and dynamic VFX.
- Joust-inspired Arena Trial: A playable sequence in a dynamic arena featuring animated GLB character models, allowing operators to test horizontal and vertical mount movement and combat, echoing classic Joust mechanics.
- Interactive HUD and Bond Meter: A real-time Heads-Up Display (HUD) showing operator telemetry and a 'Bond Meter' for visual feedback, reflecting mount connection and performance, with dynamic visual responses to phase changes and cinematic events.
- Forge & Crafting Integration (Tripo3D API): Utilizes the Tripo3D API as a tool for generating, crafting, and loading animated 3D assets (GLB models) for characters, mounts, and environmental elements, simulating 'Forge-Avatars' systems for dynamic content integration.
- Real-time Ember Particle System: A continuously active, unifying visual motif of glowing ember particles flowing across all application phases, with dynamic intensity and synchronized bursts reacting to cinematic events and phase changes.
- Dynamic Cinematic Camera System: A robust camera system capable of complex cinematic fly-throughs, dynamic cuts, and active camera switching between main gameplay views and event-driven cinematic sequences.
- Post-Process Glitch VFX: Dynamic post-process glitch overlays and shader effects applied across active cameras, enhancing the VLAAD Gothic 'Void Mode' aesthetic and signaling critical application states or cinematic transitions.
- Avatar Agentic Personality System (Dendritic-Linked): Implements a cognitively-guided avatar agent using a dendritic-linked personality network. This system serves as a tool to interpret pilot intent and environmental context via a pseudo-memory layer, biasing behavior selection through a GOAP (Goal-Oriented Action Planning) / Behavior Tree. It generates deterministic, adaptive animation sequences from a Behavior Action Repository, weighted by signal pulses, ensuring player-readable intent and SSOT compliance.

## Style Guidelines:

- Color scheme: Dark theme, grounded in 'Void Mode' principles for high contrast.
- Primary color: Vibrant molten orange (#FF8C33), representing ember particles and core interactive elements. HSL: 25, 100%, 60%.
- Background color: Deep charcoal with a warm undertone (#231E1A), offering a stark contrast for focus on vibrant elements. HSL: 25, 20%, 12%.
- Accent color: Bold, striking crimson red (#CC171E), used for critical alerts and glitch effects. HSL: 355, 80%, 45%.
- Headline font: 'VLAAD Gothic' (sans-serif) for narrative hooks and high-impact text. Note: currently only Google Fonts are supported.
- Body font: 'Inter' (grotesque-style sans-serif) for clean, objective readability in telemetry and instructions.
- Code font: 'Source Code Pro' (monospaced sans-serif) for any technical output or console-like interfaces.
- Sharp, vector-based icons with a digital-gothic aesthetic, possibly featuring subtle glitch or glow effects for interactive states.
- Immersive full-screen layouts with cinematic framing, dynamically positioned UI elements, and distinct 'lanes' or 'levels' for gameplay navigation, ensuring a focus on visual impact within 'Void Mode'. Layouts adapt to support dynamic camera transitions and GLB model display.
- Fluid transitions between application phases, persistent ember particle animations with dynamic intensity, complex cinematic camera fly-throughs and cuts, animated GLB model sequences triggered by events, and dynamic glitch overlays for full VLAAD Gothic 'Void Mode' immersion.
