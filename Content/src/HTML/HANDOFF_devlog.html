Implementation Pattern — Dev Gate

Advanced Settings / Developer Access Key

The fastest implementation: a single hidden trigger in the cockpit that reveals a Dev Settings panel. No new architecture required — just a toggle gated by a local key. This preserves all dev tooling without surfacing it to players.

Suggested Implementation Pattern
Add a small unlabelled gear icon to the command bar (far right, after existing status pills). Clicking it prompts for a 4-6 character access key. On correct entry, a slide-out Dev Panel opens showing: raw API endpoint selectors, engine telemetry, ERC contract type, VLAAD system label, pipeline health. On incorrect entry or dismiss, nothing changes in the main UI.
// Dev gate pattern (vanilla JS — drops into existing cockpit script)
const DEV_KEY = "CST04"; // change before ship

document.getElementById('dev-trigger').addEventListener('click', () => {
  const input = prompt("ADVANCED ACCESS KEY:");
  if (input === DEV_KEY) showDevPanel();
});
The dev panel should remain fully functional — this is not a removal, it's a routing. Everything that exists now stays. It just moves one click deeper for players who shouldn't see pipeline internals.
