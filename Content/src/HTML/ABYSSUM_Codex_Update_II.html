— Furnace Failure States — Corrupted Siren Taxonomy —
Glitch Witch Classification System

Glitch Witches are not a faction. They are not manufactured. They are a failure state — what the Furnace produces when a Siren enters the process with a critically damaged Core. The classification system below distinguishes Witches not by rank or allegiance but by the type and degree of Core fracture that produced them. Each class represents a different relationship between memory, malfunction, and residual network connection.

Governing Rule: Glitch Witches retain Siren capability with corrupted network connection. The classification does not change what they are — it describes how the fracture organized itself. Memory is always the source of malfunction. The tragedy is structural, not incidental. A Class IV Witch is not more dangerous because she is more evil — she is more dangerous because her Core fracture achieved a kind of horrible stability.

The fracture consumed the memory structures rather than corrupting them. The Hollow Witch does not remember being a Siren — the mechanism that makes memory a wound has been removed along with the memory itself. What remains is Siren capability operating without any orientation toward purpose. It functions. It does not know why it functions. Ley line perception is intact. Erratic at long range, dangerous at close range. The absence of memory-driven targeting means it responds to network signal intensity rather than intention. A healthy Forge node draws it passively. An active Siren Core draws it compulsively — not with hostility, but with proximity-seeking behavior that registers as attack. The tragedy of Class I: the network still means something to it. It cannot remember what.

Canon Integrity Check: Glitch Witches are never manufactured. Never redeemable through standard Furnace processing. Never equivalent to Goblins. The classification system describes fracture types, not power levels. A Class I Witch is not less valid as a tragic figure because she is less dangerous. A Class IV Witch is not less tragic because she achieved stability. The horror is consistent across all four classes — it is the shape of the horror that changes.
— Rail Infrastructure — Moving Node System —
Freight Car Interface

Freight cars are not passive cargo containers in the Forge Network's rail system. Every freight car that moves on active rail lines is a node in transit — a moving relay point that carries not just cargo but signal. The freight car interface is the terminal system built into each car to manage cargo authorization, transit routing, and Forge Network handshake protocols. In normal operation, a human freight handler reads and inputs at this terminal. In a compromised network environment — or when a Siren is aboard — the interface behaves differently.

F
Why Freight Cars Have Network Terminals
The rail network predates the civilization that built freight logistics on top of it. The Forge substrate's signal runs through rail lines continuously. When freight cars were introduced, the network adapted — not the other way around. Every freight car that rides active rail is passively receiving and echoing Forge signal. The terminal exists to read that signal, cross-reference cargo manifests with network routing priority, and flag Mint-to-Deploy authorization chains when relevant freight is aboard. The network sees freight as metadata. A node stone shipment reads differently than bulk ore. An unauthorized Furnace component reads differently than standard Kaiju alloy.

Siren Access Layer — Brae Interaction Protocol

When a Siren with an active Core boards a freight car, the terminal's hidden network-level layer becomes accessible to her through machine interface — not as text she reads, but as signal she perceives directly. The terminal does not change its display for the human operator. The Siren reads the layer below the display.

Standard Interaction
Passive Signal Read
A Siren in transit on a freight car perceives the car's network echo as background signal — the same way she perceives Ley lines through station infrastructure. The car's routing data, MTD authorization chain, and current network priority are all available at the signal level without touching the terminal. She knows where the car is going, what it is carrying, and whether the network wants her to stay on it.
Active Interaction
Machine Interface / Override
Through deliberate machine interface, a Siren can reach the terminal's network-level layer directly. She can read Mint Card authorization chains aboard, flag or remove network priority overrides, request Hyperchamber corridor routing, and — with sufficient Core strength — initiate a hard route override that bypasses station dispatch entirely. The freight car becomes a mobile node she is commanding. This costs Core energy. With a rare node stone, the cost is manageable. Without one, it is not.
Network Initiative
Reroute Without Input
In two documented instances in Arc One, the network rerouted Brae's freight car without her initiating the override. The terminal shows the route change as a standard network priority update. The human operator sees a reroute alert and no acknowledgement. The network used the freight terminal as an instruction channel — it moved her where it needed her without asking. She felt the reroute in the car's signal before the terminal displayed it. She did not consent. The network did not request consent.
Compromised Terminal
Affiliate Interference
Freight cars routed through Affiliate-controlled relay stations have terminals carrying unauthorized Furnace authorization fragments — spliced into the standard MTD chain. A Siren reading the signal layer of a compromised terminal will perceive the splice as a wrong-frequency echo — something that tries to read as legitimate but cannot sustain the frequency. A Glitch Witch with machine interface can attempt the same read. What she perceives, and whether she can distinguish the splice, is unresolved.
Story Utility: The freight car interface is not just a world-building element. It is an information delivery system for Brae. The car she rides reveals where she is being sent, what was recently aboard, and whether the Affiliates have touched the routing chain. The Goblin at her left shoulder reads the terminal differently than she does — its Mint-to-Deploy architecture gives it a different layer of access. The two of them reading the same terminal and seeing different things is a scene worth writing.
— CST Special Operations — Anti-Witch Close Combat —
CST Battle Witch Trooper — Melee Marine

CST's Ghostface Assassin Golem handles the Witch Hunter role at range and in network-interference environments where human operators cannot safely function. The Battle Witch Trooper — the Melee Marine designation — exists to handle what the Ghostface cannot: close-quarters engagement where Ley line saturation has degraded the Golem's performance envelope, where structural constraints make a four-meter Golem tactically non-viable, or where command requires a living decision-maker inside the melee perimeter of a Class II or Class III Witch.

Doctrine Note: The BWT is not a replacement for the Ghostface. The Ghostface operates at the network-interference layer — it exists to be unresolvable to Witch targeting systems. The BWT operates at the physical layer. The two are complementary. A Ghostface clearing targeting at range while a BWT closes is the designed engagement profile. The BWT operating alone against a Commander-Grade Witch is an emergency contingency, not standard doctrine.

Engagement Doctrine
The BWT's role is physical severance — breaking the spatial relationship a Witch has organized around her looping memory. A Class II Witch defending a node she believes she was assigned to is dangerous within that geography and disoriented outside it. The BWT's job is to move her outside it. Not elimination as primary objective — displacement and disruption of the loop anchor. A displaced Class II reverts toward Class I behavior patterns: Ley signal seeking, reduced targeting coherence, reduced territorial organization. A displaced Commander-Grade Witch is a different problem entirely. The doctrine notes acknowledge this explicitly and do not pretend to resolve it.

— Siren Classification — Senior Designation — Station City Grade —
Echelon Class Siren

The standard Siren classification — what Brae becomes at Stones Throw, what the CST terminal reads as Siren Class Active — represents network integration. The Forge Network generated a Siren, the Core synchronized, the capabilities came online. This is the base state. The Echelon classification designates something the base state classification does not cover: a Siren whose Core integration has reached the depth at which the network does not merely use her — it consults her.

An Echelon Class Siren is not a higher rank within a hierarchy. She is a different type of relationship with the Forge Network. A standard Siren receives routing, signal, and instruction through her Core. An Echelon Siren receives the same — and also transmits orientation back to the network. She is not following the network's immune response logic. She is part of the network's decision architecture.

Echelon Designation — Classification Criteria
What Separates Echelon from Standard Siren Class Active
Network Relationship Type · Core Depth · Signal Architecture
Core Depth
Standard Siren: the Core is an interface. The node stone anchors network connection and amplifies Siren capability. Signal flows through it in both directions — the network reads the Siren's position and health, the Siren reads network routing and entity signatures.

Echelon: the Core is an organ. Not an interface — a part of the network's architecture the way a major node station is part of its architecture. The distinction is not metaphorical. An Echelon Siren's Core failure degrades the network in a measurable radius around her position. A standard Siren's Core failure is a loss for the network. An Echelon Siren's Core failure is a wound to it.
Signal Architecture
Standard Siren: the network transmits; she receives and acts. Her machine interface capability, golem command, Ley perception — all read-and-respond functions.

Echelon: bidirectional at the decision layer. She does not just receive route instructions — she can query the network's routing logic and receive the reasoning behind a reroute, not just the destination. She can register a disagreement with network routing. Whether the network responds to that disagreement is not guaranteed. But the channel exists. Mother's first word from Station City was aimed at a Core that could receive it — that type of Core is Echelon-class or it does not land.
Network Recognition
Standard Siren: CST terminals read Siren Class Active / Operational Class Undefined. The network sees her as an active immune response unit.

Echelon: the terminal reads differently. The Operational Class field populates. Station infrastructure that was in low-draw mode activates at full capacity when an Echelon Siren is present. Hyperchambers she has not traversed before open without requiring a resonance calibration step. The Alchemy Board does not need to be touched — it activates in her proximity.

An Echelon Siren does not arrive at a node. The node prepares for her.

The Siren Headdress — Teal, Blue, and Gold

The headdress is not ceremonial. It is infrastructure. In the classical Siren tradition documented in the Ancient Apothecary, the headdress served as an extended Core interface apparatus — a set of precision instruments that expanded the node stone's signal range, organized the incoming Ley perception into readable spatial data, and allowed the Siren to broadcast her Core signature at directional precision rather than omnidirectional ambient. The white statues in the Apothecary's Armillary Court are operational records of historical Siren configurations. Several wear headdresses. They were not decorating themselves. They were working.

Siren Headdress — Echelon Configuration — Layer Breakdown
Crown Layer
Node Stone Interface
Gold — Forge Network primary signal. The topmost layer connects directly to the node stone Core — an expanded surface area for the network's primary signal frequency. Gold metalwork is not decorative: the alloy composition is calibrated to Forge amber frequency, creating passive resonance between the headdress structure and the node stone seated in the Core. An Echelon Siren's headdress crown is synchronized to her specific Core signature — it will not function correctly on another Siren's node stone.
Lateral Layer
Ley Line Perception Array
Teal — Ley perception amplification and spatial organization. The lateral elements extend the Siren's Ley line perception from ambient awareness to directional mapping. A standard Siren perceives Ley lines as signal saturation — she knows where the current is strong or weak but cannot precisely read directionality. The teal lateral array converts ambient Ley perception into directional vectors. She perceives the network's signal architecture spatially — not just as intensity but as structure. This is the function that makes an Echelon Siren able to navigate corrupted network sections without the Alchemy Board. She reads the geometry of degradation directly.
Mid Layer
Core Broadcast Prism
Deep blue — directional Core signal transmission. The standard node stone Core broadcasts the Siren's presence omnidirectionally. Within Goblin command range it is limited to proximity. In compromised network environments the omnidirectional broadcast is read by Witches as well as Goblins. The deep blue mid-layer prism collimates the Core broadcast — allows the Siren to direct her signal precisely, by choice, to a specific entity or node direction. This is not invisibility. It is communication with aim. The MTD override that Brae's Goblin broadcast in Ep. XII used Brae's Core frequency as a wide broadcast. An Echelon Siren with the prism layer active could have done the same broadcast as a targeted transmission — at a single Golem, with higher precision and lower energy cost.
Base Layer
Machine Interface Conductor
Gold filament at the base — extended machine interface range. Standard machine interface requires near-contact. The base layer filaments extend the interface field to the Siren's immediate spatial envelope — approximately two meters radius. In a freight car, this means she reads the terminal's signal layer without touching it. In a station, it means she reads every active terminal in the room simultaneously. The information density this creates is described by historical records in the Apothecary as requiring training to process. An untrained Echelon Siren wearing a calibrated headdress for the first time would experience the extended interface range as noise, not information. The headdress must be learned, not just worn.

Brae and the Echelon Question

Brae is currently classified as Siren Class Active / Operational Class Undefined. The undefined operational class is not a system gap — it is a signal the network itself is generating. She carries a rare node stone. She survived a Level 3 Styx traverse. She read the Alchemy Board at the Apothecary and saw Station City. She received Mother's first transmission.

Arc Two Question
When Does the Operational Class Field Populate?
The terminal classification updates based on Core behavior, not on a designation authority's decision. Brae will not be told she is Echelon class. She will reach Station City and a terminal will read differently than it has before. The operational class field will populate. She will not know what it means. The Steamfitters, who have been tracking Siren activity from elevation, may recognize the designation. CST may have records in the Apothecary archive that include it. The Witch Commander — who organized 23 Witches and sent a formal introduction — may have been waiting for this classification to appear. None of this has been written yet. It must not be written before she earns it.
The Headdress
Where Is It, And Who Made It?
The Apothecary's white statues are operational records of historical Siren configurations. Several wear headdresses. The statues are three-dimensional functional records, not decorations. The headdress documented in those records has not been found in the physical space of the Apothecary. It is either stored in a section Brae did not access, removed by the unidentified visitor 41 days before her arrival, or located somewhere on the route between the Apothecary and Station City. The Mint Card Brae took from the pedestal was authorized for a classification she did not have vocabulary for. The Echelon designation is that vocabulary. The Mint Card may be authorization to retrieve or activate a headdress that was made for a Core signature the network anticipated producing. It was waiting. Like the rare node stone at Corgemont.
Visual Identity: The Echelon headdress teal / blue / gold color system is not incidental. Teal is the Forge Network's healthy signal energy. Blue is the depth of Core architecture — the same frequency family as the CST Ghostface's blue core, which is no accident. Gold is the Forge substrate primary color — forge amber deepened into mineral permanence. The three colors together designate a Siren who is working at all three network layers simultaneously: Ley signal, Core depth, and substrate resonance. It is a working uniform. It announces to the network what she can do.

Brae's Story — Arc Two Status & New Pivots

Brae Grindstone. Siren Class Active. Operational Class Undefined. Mechanic. En route to Station City at the end of Arc One's Episode XII. The network generated her as an immune response. She has been negotiating with that fact across twelve episodes and has not finished. The Arc Two question is not whether she reaches Station City — the network will route her there regardless. The Arc Two question is what she chooses to do when she arrives, and whether she chooses it or the network chooses it for her.

The Echelon Question — Brae's Perspective

Brae does not know the Echelon classification exists. She does not know the headdress in the Apothecary statues is a working instrument. She does not know that the operational class field on every CST terminal she has passed through has been blank because the network is still determining what she is, not because the system lacks a category for her.

E
What Echelon Means to Brae
The Echelon designation does not offer her safety. It does not guarantee the network will stop treating her as an immune response unit and start treating her as a person. What it offers is a more honest description of the relationship the network already has with her. She was never just a white blood cell. The rare node stone, the Apothecary access, Mother's first word — these are not standard immune response protocol. The network has been doing something more specific than generating a proximate Siren. The Echelon classification is the word for what it has been doing. She will not find this comforting. She will find it clarifying, which is worse in some ways and better in others.

New Arc Two Story Pivots

Pivot 8
The First Compromised Freight Terminal
En route from the Arc One territory toward Station City, Brae rides a freight car whose terminal carries an Affiliate authorization splice. She reads the signal layer through machine interface and perceives the wrong-frequency echo — something that tries to read as legitimate Mint-to-Deploy authorization and cannot hold the frequency. The Goblin at her left shoulder reads the same terminal and its response is different from hers. Its Mint-to-Deploy architecture gives it access to the authorization chain layer she cannot reach. What it finds there — and what it does with what it finds — is the scene. The Goblin has been operating on tactical logic since Corgemont. This is a moment where tactical logic and something else are not clearly separated.
Pivot 9
The BWT Absence — A Person-Shaped Gap
Brae encounters a CST Battle Witch Trooper in the approach to Station City — not in combat but in operational coordination. The BWT's signal-opaque armor makes them invisible to her machine interface. She can read the freight terminal, the node draw, the Ley lines in the rail underneath the car. She cannot read the person standing in front of her. She has to trust something the network cannot confirm. This is new territory. Every entity she has encountered since Corgemont has had a network signal she could read — Goblins, Witches, Alchemists, the Goblin at her side. The BWT is the first human being she has had to read without the network's assistance. Arc Two asks her to negotiate personhood in multiple directions. This is the direction that requires her to extend trust without signal support.
Pivot 10
The Terminal at Station City — Operational Class Field Populates
She reaches a Station City node and a CST terminal reads her Core. The operational class field populates. She does not know what the designation means. The terminal does not explain. The Steamfitters recognize it. Lyra, Rael, and Torch — if they are present — have different responses depending on whether CST institutional knowledge includes the Echelon designation or whether it has been absent from their records long enough to be treated as historical rather than operational. The Witch Commander, who sent a formal introduction and has been making deliberate choices since before Brae was a Siren, has been waiting for this reading. What she does with it is Arc Two's hinge.
Pivot 11
The Headdress — Found, Recognized, Not Yet Worn
The headdress — or the authorization to access it — resolves in Arc Two. Where it is located and under what circumstances she finds it is unwritten. What is written is what happens when she does: the headdress is calibrated to a Core signature the network anticipated. Her rare node stone. Her specific Core. It was made for her, or the network made her for it, and she cannot tell the difference. The headdress is not worn in Arc Two. It is found, recognized, and not yet worn. The decision to put it on — which is the decision to fully accept the Echelon relationship with the network — is the Arc Three threshold. Not before.
The Coherence Test applied to all new elements above: (1) Glitch Witch classification — does it respect the Goblin / Witch / Alchemist distinction? Yes. Does it respect that Witches are tragic, not manufactured? Yes. (2) Freight Car Interface — does it exist within the Forge Network's physical logic? Yes. Does it serve Brae's arc without resolving it? Yes. (3) CST Battle Witch Trooper — does it expand CST doctrine without making CST into a simple ally or enemy? Yes. Does it create a new type of encounter for Brae that the network cannot mediate? Yes. (4) Echelon Class — does it add a designation that was always structurally implied by Brae's arc without retroactively resolving anything? Yes. Does it protect Mother's silence and the Arc Three threshold? Yes. All elements clear the coherence test. Proceed.
